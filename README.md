# Barbearia Drudi ✂️

## 📖 Descrição
Projeto de site institucional para uma barbearia, com foco em apresentação dos serviços e visual moderno.

## 🚀 Funcionalidades
- Apresentação da barbearia
- Lista de serviços
- Layout responsivo

## 🛠 Tecnologias
- HTML
- CSS
- JavaScript

## ▶️ Como executar
Basta abrir o arquivo `index.html` no navegador.
